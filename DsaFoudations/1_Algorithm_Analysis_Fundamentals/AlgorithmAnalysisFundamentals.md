- What is Time Complexity?

- Counting operations
- Understanding input size (n)

Common Complexities:
- O(1) - Constant Time
- O(log n) - Logarithmic Time
- O(n) - Linear Time
- O(n log n) - Linearithmic Time
- O(n²) - Quadratic Time
- O(2ⁿ) - Exponential Time
- O(n!) - Factorial Time
